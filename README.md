# 🏀 Sport Blog Backend

The **backend** of the Sport Blog project is a REST API for managing sports articles and user data.  
It was built with **Express.js** and **PostgreSQL (Sequelize ORM)** and provides the server-side logic of the application.

🔗 **Frontend:** [Sport Blog Frontend](https://github.com/SergiiBzn/sport-blog-frontend)  
🔗 **Live Demo:** [https://sport-blog-frontend.onrender.com/](https://sport-blog-frontend.onrender.com/)

---

## 🧩 Features
- REST APIs for managing articles and user data  
- Full CRUD operations (Create, Read, Update, Delete)  
- Connection to a PostgreSQL database via Sequelize  
- Environment variable management with dotenv  
- Cross-Origin Resource Sharing (CORS) enabled  

---

## ⚙️ Tech Stack
- **Node.js**, **Express.js**  
- **PostgreSQL**, **Sequelize ORM**  
- **dotenv** for configuration  
- **CORS** for API access  

---

## 🚀 Installation & Start

```bash
git clone https://github.com/SergiiBzn/sport-blog-backend.git
cd sport-blog-backend
npm install
npm run dev
```
